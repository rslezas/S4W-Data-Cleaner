About This Project

The S4W Nepal Flood Event Repository is an interactive platform designed to organize, document, and visualize flood events in Nepal.

This prototype combines documented flood information from Nepal's Department of Hydrology and Meteorology (DHM) with streamflow observations from the S4W cleaned flow dataset.

The repository currently includes the September 27–29, 2024 Kathmandu Valley flood event, along with demonstration records used to test the map, filters, and timeline.

Future development will focus on incorporating additional flood events, verified geographic information, and groundwater data.

Data Sources & Methodology

1. S4W Streamflow Data

Streamflow observations were extracted from the S4W cleaned flow dataset (Flow_SW_Clean). Measurements from September 26, 2024, provide pre-flood hydrological context.

2. Government Flood Documentation

The September 27–29, 2024 flood event was documented using a situational report from Nepal's Department of Hydrology and Meteorology (DHM).

View DHM Flood Report

3. Map Visualization

The interactive map uses Leaflet and OpenStreetMap. The Kathmandu reference circle is illustrative and does not represent a verified flood boundary. Three demonstration markers are included to test the website's functionality.

4. Current Data Limitations

The available September 26 streamflow observations do not establish flood conditions during September 27–29. Groundwater measurements and verified flood extent data have not yet been incorporated into the repository.
